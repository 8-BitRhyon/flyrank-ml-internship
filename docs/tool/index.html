What this tool does, and what it does not

It applies the transparent value rule from the paper, not the 25-feature model. Tier medians are computed from the rows you load, so the queue is relative to your own list. Deep pages (position above 20) and pages below 500 impressions are excluded. The result is decision-support for review order, not a forecast of recovered clicks.

Read the paper for the method, the validation, and the limits. The API is at flyrank-ctr-queue.rhyonfs.workers.dev.
